# Themes Page

This is just where I point my html at to choose whatever "theme" I will use for the background of the front page. As you can see, I have made quite a few themes through experimenting with three.js.

I was going to implement a "themes menu" where the user could open a sidebar menu and choose from the selection of themes, although I realized this was one pretty ambitious and would take a while to figure out, and two was just not really a priority.

I did have a lot of fun experimenting with three.js, and if you do want to preview the different themes here, just "cmd + f" for the "loadTheme" event listener. There's like 3 times that is referenced, but this is the line that specifically calls for the js file. 

`loadTheme("stars.js");`

Just change the words "stars" to whatever other theme you want to see.
